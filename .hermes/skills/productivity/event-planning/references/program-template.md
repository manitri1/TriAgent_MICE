# Program (Agenda) Template

Use this template to create the event program/agenda. Replace placeholders in <angle brackets>.

---
Event: <EVENT_NAME>
Date: <YYYY-MM-DD>
Time: <START_TIME> — <END_TIME>
Venue: <VENUE_NAME>
Target: <TARGET_AUDIENCE>
Objectives:
- <objective 1>
- <objective 2>

---

Schedule (detailed)

- <HH:MM> — Staff arrival & set-up
- <HH:MM> — Presenter rehearsal (if needed)
- <HH:MM> — Registration open
- <HH:MM> — Opening & welcome remarks (speaker, 5-10 min)
- <HH:MM> — Presentation block 1 (format: X min presentation + Y min Q&A) x <N>
- <HH:MM> — Break (10-15 min)
- <HH:MM> — Presentation block 2 x <M>
- <HH:MM> — Judging / Q&A consolidation
- <HH:MM> — Awards & closing (20 min)
- <HH:MM> — Networking / photo

Notes for presenters
- File format accepted: PDF or PPT. Max file size: <e.g. 10MB>
- Presentation time: <7 min presentation + 3 min Q&A> — please rehearse for time.
- Arrival for rehearsal: <time>

Logistics checklist
- Projector & HDMI cable
- Wireless microphones (x2)
- Speaker/PA system
- Laptop with presentation clicker
- Registration desk and badges
- Printed schedule (optional)

Save this file as `program-template.md` and copy into project proposal folders under `./proposals/<slug>/`.
