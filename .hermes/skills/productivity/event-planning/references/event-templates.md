# Event templates and examples — Local Content Contest

This reference contains ready-to-use templates, checklist, and example file paths for one-day local contests. Copy these into a session-specific folder `proposals/<project-slug>/` and adapt.

1) Program (contest-program-draft.md) — minimal example
```
# <Project Title> — Program (Draft)
Date: YYYY-MM-DD
Venue: <venue>

17:00 — Staff arrival & AV setup
17:30 — Presenter rehearsal (priority)
17:50 — Check-in opens
18:00 — Opening remarks (10 min)
18:10 — Presentation Session 1 (4 presenters, 10 min each)
19:00 — Break (10 min)
19:10 — Presentation Session 2 (4 presenters)
19:50 — Judging tally & short deliberation (10 min)
20:00 — Award ceremony (20 min)
20:20 — Networking & photo (20~30 min)
21:00 — Finish & pack down
```

2) Registration guide (registration-guide.md) — fields to collect
- Team name / Individual name
- Representative name / Contact phone / Email
- Presentation title
- Short summary (200-300 chars)
- File upload: proposal PDF or PPT (max 10MB)
- Team member list (up to 4)
- Consent: photo/video & promotion use
- Submission filename format: [teamname]_project.pdf

3) Canva prompts (canva-prompts.txt) — starter
- "16:9 presentation, Korean language, modern clean layout, ocean blue (#0B72B9) + coral accent (#FF6B6B), Noto Sans KR, 12 slides: cover, summary, goals, timeline, program, registration, judging, budget, logistics, media, risk, next steps. Include QR code placeholder."
- Per-slide: Title text, body bullets, presenter note (1-2 lines), image placeholder (e.g., 'hero image: Pohang coastline')

4) AV checklist (av-checklist.md)
- Projector + laptop + HDMI
- Microphones: lapel or handheld x2 + spare batteries
- Speakers + mixer (if needed)
- HDMI adapters (USB-C, Mini DisplayPort)
- Clicker/laser pointer
- Spare laptop and USB with backup slides
- Photographer / Videographer contact & brief

5) Budget template (budget-template.csv)
- Item,Estimated,Actual,Notes
- Equipment rental,120000,,
- Photography/editing,100000,,
- Host/MC fee,50000,,
- Printing/programs,20000,,
- Contingency,49000,,

6) Usage note for agents
- Save session artifacts under `/opt/data/proposals/<project-slug>/` and return absolute paths in replies.
- Default language: Korean for user-facing content.
- After writing templates, offer conversion steps to DOCX/PDF and PPTX. If system tools are missing, instruct user how to convert locally.
