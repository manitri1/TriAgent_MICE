# Registration form fields (copy-paste for Google Form / Naver Form)

- Event name (pre-filled)
- Team name (if applicable)
- Representative name
- Representative contact (phone/email)
- Team member names (comma-separated)
- Presentation title
- Presentation summary (100-200 characters)
- Presentation file upload (PDF or PPT, max 10MB) — optional
- Preferred presentation format: Individual / Team
- Consent to photography/video: Yes / No
- Agreement to use submitted idea for promotional purposes (checkbox)

Notes: Add a required field for 'Preferred presentation time' only if you select time slots in advance.
