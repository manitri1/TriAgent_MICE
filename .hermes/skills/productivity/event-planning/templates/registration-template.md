# Registration & proposal template

Use this as fields for Google Form / Naver Form / custom intake.

1) Submission type: [Individual] / [Team]
2) Team name (if any)
3) Representative name
4) Contact phone
5) Contact email
6) Organization / affiliation
7) Proposal title
8) Short summary (200-300 chars)
9) Detailed proposal (file upload: PDF or PPT, max 10MB)
10) Number of presenters for live session
11) Technical needs (power, monitor, special equipment)
12) Consent: photo/video use for promotion [Yes/No]
13) Agreement: I confirm this is original work [checkbox]

Admin notes
- File naming convention: [TeamName]_pohang_proposal.pdf
- If more proposals than live slots, run pre-screening based on summary and judge scores
