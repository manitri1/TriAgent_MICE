# Program template (single-room contest)

Event: [Event name]
Date: [YYYY-MM-DD]
Venue: [Location / Room]
Target attendance: [N]

---
Timeline (example for 50 attendees)

16:30  Venue opens / staff arrive / AV check
17:00  Presenter rehearsal (selected presenters)
17:30  Registration opens / welcome desk
17:50  Doors close / final checks
18:00  Opening remarks (MC / organizer) 10'
18:10  Session 1: Presentations (4 x 10' = 40')
18:50  Short break / networking (10')
19:00  Session 2: Presentations (4 x 10' = 40')
19:40  Judges deliberation (10')
19:50  Awards & closing remarks (20')
20:10  Networking / photo / exhibit (20'-30')
20:40  Venue clear / staff pack-down

Notes
- Presentation format: [7' presentation + 3' Q&A] or [5'+2'] 
- Keep 10-15 minute buffer between major program blocks for small overruns
- Designate staff for: registration, stage/AV, timekeeping, ushering, photography

Deliverables
- Final program PDF for printing (A4) and digital
- Presenter instructions (arrival time, file specs, contact)
- Run-sheet for MC and tech (line-by-line)
