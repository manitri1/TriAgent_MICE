# 전략 기획서 템플릿 (팀용) — 빈 양식

문서 헤더
- 문서명: [예: 포항 콘텐츠 발굴 콘테스트 전략 기획서 - 팀명]
- 작성자(팀): [팀명 / 작성자 이름]
- 작성일: [YYYY-MM-DD]
- 연락처(팀 대표): [이메일 / 핸드폰]
- 프로젝트(행사)명: [예: 포항 MICE 아카데미]
- 행사 일시·장소: [예: 2026-11-03 18:00 · 파랑뜰 2층]

---

1) 요약 (Executive Summary) — 150~250자
- 프롬프트: 우리 팀의 제안은 무엇인가? 누구를 위해, 어떤 가치를 만들려는가?

2) 기획 취지(Why) — 200~400자
- 프롬프트: 이 사업이 어떤 문제를 해결하나? 지역적 근거/관찰을 짧게 적으세요.

3) 브랜드 및 슬로건
- 권장명(1) + 대안(2~3) + 2개의 짧은 슬로건

4) 목적(Objectives)
- 정량목표(숫자/기한) / 정성목표(네트워크, 파일럿 등)

5) 대상(Target)
- 1차 핵심대상 / 2차 확장대상 및 각 대상의 동기(한 줄)

6) 지향점(Positioning)
- 우리 행사의 차별점(한 문장)

7) 기대효과(Impact)
- 단기(0~3개월) / 중기(3~12개월) / 장기(1년+)

8) 핵심 전략(How)
- 채널(무엇/누가/언제/어떻게)
- 심사·지원(기준/멘토링/시상)
- 운영(현장 흐름, AV, 리허설)
- 자원/예산(주요 항목)

9) KPI 및 측정방법
- 표 형식: 지표 | 목표값 | 측정방법 | 담당자

10) 일정(로드맵)
- D-90 / D-60 / D-30 / D-14 / D-7 / D-Day / D+14

11) 예산(요약)
- 항목별 금액 & 근거(견적 추정)

12) 리스크 및 대응(Top 5)
- 리스크 | 심각도(High/Med/Low) | 대응(Plan B) | 담당자

13) 이해관계자 및 역할
- 표 형식: 이해관계자 | 역할 | 연락처/비고

14) 산출물(Deliverables)
- 행사 전 / 당일 / 사후 산출물 목록

15) 제출 안내
- 파일명 규칙: teamname_strategy_YYYYMMDD.md
- 제출 형식: Markdown or Google Doc

작성 힌트
- 간결하게(각 섹션 3~6문장)
- 수치/근거 명시
- 현실성 검증: 예산·시간·인력 체크
