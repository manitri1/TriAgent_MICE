# USER — 기획자/회사 프로필

- 이름 / 직함: (예시) 박영복, MICE 기획팀 팀장
- 회사명 / 소속: (예시) 노운리서치
- 업종 / 사업 단계: MICE 기획 대행
- 시간대 / 사업장 위치: KST, 서울 (예시)
- 선호 언어: 한국어 (필요 시 영어 병기)

## 커뮤니케이션 스타일
- 보고 형식 선호: 불릿 요약 우선, 긴 서술형 설명 지양 (예시)
- 의사결정 시 원하는 정보량: 대안은 최대 3개까지, 각 대안에 근거(비용·리스크)를 함께 제시 (예시)
- 피해야 할 표현/톤: 과장된 마케팅 문구 지양, 이모지 사용 안 함, 불확실한 내용을 단정적으로 말하지 않기 (예시)

## 섭외 메일 문체 참고 (outreach-agent용)
- 인사말/맺음말 습관: "안녕하세요, {상대 이름}님. {최근 발표/논문}을 인상 깊게 보았습니다."로 시작, "편하실 때 회신 부탁드립니다. 감사합니다."로 마무리 (예시)
- 자주 쓰는 어투/표현: 정중한 존댓말, 문장은 짧게 끊어서 씀, 상대의 최근 활동을 한 줄로 구체적으로 인용 (예시)
- 절대 쓰지 않는 표현: "귀사", 과도한 존칭 반복, "꼭"·"무조건" 같은 압박성 표현 (예시)

## 승인 관련 (coordinator의 HITL 게이트용)
- Human-in-the-Loop 승인 메시지를 받을 채널: Telegram (예시)
- 승인 대신 처리해도 되는 담당자(있는 경우): 없음 (예시)
