# 저작권 리스크 검토 및 운영 권장 절차

작성일: 2026-08-07
기준 문서: 포항 지역 콘텐츠 발굴 콘테스트 (행사명·목적은 inputs의 표준 카피를 따릅니다)

## 1. 검토해야 할 핵심 저작권 이슈

1) 원저작권 귀속 확인
- 출품작이 출품자 본인의 창작물인지, 또는 출품자가 정당한 사용권을 보유한 콘텐츠인지 확인해야 합니다.
- 표절·무단전재 여부 검증 필요.

2) 제3자 권리(타인 저작물·초상권) 사용
- 사진·음원·영상·일러스트·텍스트 등 타인의 저작물이 포함되면 사용권(라이선스) 또는 서면허가가 필요합니다.
- 인물(모델) 출연 시 초상권·동의서 확보 필요.

3) 오픈소스·외부 라이브러리 이용 시 라이선스 준수
- 코드·데이터·템플릿은 라이선스를 확인(예: GPL, MIT, Apache)하고 조건을 준수해야 합니다.

4) 2차적저작물(편집·배포) 권리
- 주최 측에서 편집·홍보용으로 2차적저작물을 제작할 수 있도록, 해당 사용권을 출품자로부터 확보해야 합니다.

5) 수상 후 권리 이전·활용 조건
- 수상작의 후속지원(상용화, 홍보, 제작 등) 시 권리 귀속·범위·보상 조건을 별도 계약으로 명확히 해야 합니다.

6) 개인정보 및 촬영 동의
- 촬영·녹화물 활용(홍보·보도 등)에 대해 참가자의 명시적 동의를 받아야 합니다.

7) 분쟁·면책·배상 규정
- 제3자 권리침해 발생 시 출품자가 책임을 지고 주최측을 면책·배상하도록 규정하는 것이 안전합니다.


## 2. 운영상 권장 절차

1) 접수 단계(폼에 필수 포함)
- 원저작자 보증 서약(체크박스)
- 제3자 저작물 사용 여부(예/아니오) 및 사용 허가서 업로드 필드
- 인물 초상권 동의 확인 필드 및 동의서 업로드

2) 기술적 검증
- 표절검사(텍스트 유사도), 이미지 유사도 점검(가능하면) — 사전 필터링

3) 수상 확정 전 검증
- 수상자에게 권리 증빙(허가서 원본) 제출 요구
- 미제출 시 수상 취소 규정 명시

4) 사후 처리
- 주최측이 편집·홍보용으로 사용할 수 있도록 비독점적·비상업적 사용권 확보(또는 별도 사용료 약정)
- 상용화 가능성 있는 작품은 별도 계약(라이선스 양도·수익 분배) 권장

5) 백업·대응
- 접수폼 장애·스팸 대비: 이메일 접수·수기 접수 프로세스 준비
- 침해 주장이 제기되면: 즉시 게시 중단 → 제출자 소명 요청 → 해결 / 결과 통보


## 3. 제출 시 요구 자료(권장)
- 출품자 신원 정보(이름/소속/연락처/이메일)
- 작품 원본 파일(고해상도) + 제출 포맷 명시(PDF/PPT/MP4 등)
- 제3자 저작물 사용 허가서(있을 경우)
- 모델(출연자) 동의서(사진/영상 포함 시)
- 작품 설명서(저작권자·참고자료·출처 표기)


## 4. 내부 운영 체크리스트 (검토 항목)
- [ ] 출품자가 저작권자 또는 정당한 사용권 보유 여부 확인
- [ ] 제3자 저작물 사용 시 허가서 첨부 여부 확인
- [ ] 모델 초상권 동의서 제출 여부 확인
- [ ] 표절/유사성 사전검토(필요 시)
- [ ] 수상자 권리 증빙(수상 전) 확보
- [ ] 주최측의 사용권(홍보·편집) 확보 확인
- [ ] 분쟁 발생 시 면책·배상 조항 포함 여부 확인


## 5. 법률 검토 권고
- 본 운영지침과 동의서 초안은 행사 운영상 실무 기준을 제공하기 위한 것으로, 중요한 계약·양도(특히 수상작 상용화, 독점권 이전) 시 법률전문가(저작권 전문 변호사) 검토를 권합니다.
