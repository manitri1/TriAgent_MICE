요약

이 문서는 행사 준비를 위해 권장하는 실무팀(5~7명) 구성안, 역할별 책임과 산출물, KPI, 온보딩·초기 액션플랜, 회의·커뮤니케이션 규칙을 제공합니다. 팀 규모를 선택하시면 각 멤버에 맞춘 직무카드를 추가로 생성해 드립니다.

팀 구성(옵션)

  • 옵션 A — 5인(최소): PM / 프로그램·심사 담당 / 운영·장비 담당 / 홍보·모집 담당 / 미디어·정산 담당
  • 옵션 B — 6인(권장): 옵션 A + 파트너·심사코디 담당
  • 옵션 C — 7인(안정): 옵션 B + 콘텐츠·후속지원 매니저

핵심 역할(요약)

역할핵심 업무KPI(예)
PM전체 일정·예산·대외창구·최종 의사결정일정 준수, 예산 오차 ±10%
프로그램·심사식순·심사기준·심사위원 섭외·발표자 선정심사위원 3~5인 확정
운영·장비장비 확정·리허설·현장세팅·스태프 배치리허설 문제 0건
홍보·모집접수폼 제작·홍보캘린더·참가자 확보주간 접수 증가율
미디어·정산촬영섭외·편집·영수증관리·정산영수증 100% 수집, 하이라이트 2주내
파트너·심사코디연사/심사위원/후원사 섭외·봉사자 코디연사 80% 확정, 봉사자 3명 확보
콘텐츠·후속지원수상작 후속연계·보도자료·결과보고보도자료 발행, 후속지원안 마련

RACI(주요 업무)

  • 전체 일정 확정: R=PM / A=PM / C=프로그램담당 / I=전원
  • 접수폼 오픈·모집: R=홍보담당 / A=PM / C=미디어 / I=전원
  • 장비·리허설: R=운영담당 / A=PM / C=프로그램 / I=전원
  • 심사위원 섭외: R=파트너담당 / A=PM / C=프로그램 / I=전원
  • 현장 운영: R=운영담당 / A=PM / C=스태프 / I=전원
  • 촬영·보도자료: R=미디어담당 / A=PM / C=콘텐츠담당 / I=홍보담당

온보딩 체크리스트 (신규 팀원)

  1. 역할 문서 전달 및 역할 수락
  2. 공용 드라이브 권한 부여
  3. 커뮤니케이션 채널 초대(Slack/카톡)
  4. 캘린더 공유(마일스톤/리허설)
  5. 첫 주 액션 할당(문서에 명시)
  6. 비상연락처 전달(장소·장비업체·PM)

첫 주 액션(역할별)

  • PM: 전체 일정 최종확정, 예산 배분안 확정
  • 프로그램: 발표시간·심사기준 확정, 심사위원 후보 리스트 작성
  • 운영: 파랑뜰 장비 제공 범위 확인, 장비 업체 2곳 견적 요청
  • 홍보: 접수폼 초안 제작·테스트, 홍보캘린더 초안 작성
  • 미디어: 촬영사 2곳 견적 수령, 예산정산 시트 생성
  • 파트너(선택): 연사·심사위원 1차 접촉
