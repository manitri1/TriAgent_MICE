## 폼 설명(상단 안내문)

응모 가능하며, 서면 심사를 통해 현장 발표 대상(파이널리스트)을 선정합니다. 제출 마감:
2026-10-20 23:59. 제출한 자료는 반환되지 않으며, 사진·영상 촬영 및 홍보물 사용에 동의하셔야
합니다.

## 심사 루브릭(관리자용, 응답자에게는 비공개)
- 창의성 40 / 실현가능성 30 / 지역연계성 20 / 발표완성도 10
- 서면 심사 상위 8~10팀을 현장 발표(7분 발표 + 3분 Q&A) 대상으로 선정 권장

## 2단계 접수 권장
1차 접수는 위 15문항으로 간단하게 받습니다. 실현가능성 세부 실행계획, 지역연계 협업안,
지속가능성(운영 유지 방안) 등 심층 항목은 **서면심사로 선정된 8~10팀에게만** 별도 양식으로
추가 요청하세요 — 모든 지원자(예상 30건)에게 한 번에 요구하면 응모 부담이 커집니다.

## 생성 절차 (Google Forms)
1. [forms.google.com](https://forms.google.com) → 새 양식(빈 양식) 만들기
2. 상단 제목/설명에 위 "폼 제목"/"폼 설명"을 그대로 입력
3. 위 표의 순서대로 질문 추가 — 우측 도구모음에서 문항 유형(단답형/장문형/객관식/체크박스/
   파일 업로드)을 지정하고, 필수 항목은 우측 하단 "필수" 토글을 켠다
4. 10번 문항(파일 업로드)은 "파일 업로드" 유형 선택 후 파일 최대 크기 10MB, 허용 형식
   PDF/PPT/PPTX로 제한
5. 미리보기(우측 상단 눈 모양 아이콘)로 실제 응답자 화면을 확인하고 오탈자·순서를 점검

## 배포(게시) 절차
1. 설정(⚙) → 응답 탭에서 "이메일 주소 수집" 켜기(선정 결과 자동 안내용)
2. 응답 탭 → 스프레드시트 아이콘 → "새 스프레드시트 만들기"로 응답 자동 연동
3. 스프레드시트에서 도구 → 알림 규칙 → 새 응답 제출 시 이메일 알림 설정
4. 설정 → 응답에서 확인 메시지를 다음으로 변경: "제출해 주셔서 감사합니다. 선정 결과는
   2026-10-28까지 이메일로 개별 안내드립니다."
5. 우측 상단 "보내기" → 링크 아이콘으로 공유 링크 복사(단축 URL 옵션 체크 권장)
6. 복사한 링크로 QR코드 생성(예: Google 검색 "QR code generator") 후 포스터·현수막에 배치
7. 접수 마감(2026-10-21 00:00)에는 설정 → 응답에서 "응답 받기"를 꺼서 수동으로 마감
