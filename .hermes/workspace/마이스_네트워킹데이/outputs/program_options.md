요약
- 본 문서는 단시간 행사(11:00–13:00) 안에서 실행 가능한 6가지 프로그램 구성안을 제시하고, 각 안의 구성(타임·포맷), 운영 포인트(기술·현장), 기대 효과 및 실무 체크리스트를 정리한 실행용 참고자료입니다. 행사 목적은 ‘1기·2기 수료생의 실무 연결’ 및 ‘수료생 비즈니스(서비스) 홍보 기회 제공’입니다.

1. 오픈 쇼케이스 + Q&A (Open Showcase)
- 포맷
  - 3분 피치 + 2분 Q&A × 최대 6~8팀(총 30~40분)
  - 사전 신청(선발 6~8팀), 현장 타이머·진행자 배치
- 실행 포인트
  - 제출자료: 1 슬라이드(간단 가격·서비스 표기), 샘플 준비 권장
  - AV: 마이크 1대, 노트북 HDMI 연결 1대(슬라이드) 
  - 운영: 타임키퍼·MC 필요
- 기대 효과
  - 사업 노출(가격·포트폴리오) 즉시 매칭 가능
  - 참가자 간 상호 비교·문의 유도
- 체크리스트
  - 참가자 공지(포맷·시간 엄수)
  - 슬라이드 템플릿 제공
  - 타이머·마이크 준비

2. 마켓 앨리(부스형) + 3분 스테이지 하이라이트
- 포맷
  - 소형 부스 2~6개 설치(현장 시연·샘플) + 무대에서 1팀 3분 하이라이트
  - 부스 관람 시간 30~40분(네트워킹 시간 활용)
- 실행 포인트
  - 전력·테이블·간이 배너 사전 확인
  - 안전(음식 샘플 시 위생 지침 준수)
  - 결제/문의 카드·QR 준비
- 기대 효과
  - 제품·서비스 체험으로 즉각적 거래·문의 발생
- 체크리스트
  - 부스 배치도, 전력·콘센트 확인
  - 샘플 제공 가이드라인(위생) 준비

3. 스피드 피칭 + 매칭(타겟 네트워킹)
- 포맷
  - 4~6분 짧은 대화(라운드 로빈) 여러 라운드 진행(총 20~30분)
  - 사전설문으로 관심분야 매칭(예: 케이터링·디자인·현장운영)
- 실행 포인트
  - 테이블별 호스트 1인 지정
  - 소음·시간 관리(벨·타이머) 필수
- 기대 효과
  - 짧은 시간 내 다수 접촉 → 후속 미팅 전환
- 체크리스트
  - 사전 매칭 설문(구글폼 등), 라운드표 출력

4. 사례 클리닉(피드백 세션)
- 포맷
  - 10분 사례 발표 + 20분 전문가·참가자 피드백(멘토형)
  - 사례는 사전 선발(3~4개 팀 중 1~2개 시행)
- 실행 포인트
  - 멘토 섭외(한동대·산업체·운영 전문가), 사전자료 배포
  - 발표자 비공개 자료(요약 1장) 필수
- 기대 효과
  - 실무적 문제 해결·사업 아이디어 개선, 멘토 연결
- 체크리스트
  - 멘토 명단·약력 확보(사전 동의), 피드백 포맷(시간 배분)

5. ‘우리 팀의 다음 일정’ 타임(클로징 직전)
- 포맷
  - 클로징 전 60~90초 × 최대 6팀(총 6~9분)으로 다음 행사·모집 안내
  - 슬라이드 1장(QR·링크 포함) 제출 필수
- 실행 포인트
  - 사전등록(발표 순서 확정), 시간 엄수
  - 발표 시 QR 또는 접수링크 표시
- 기대 효과
  - 행사 연계 참여 유도, 커뮤니티 활성화
- 체크리스트
  - 발표자료(1장) 수합, QR 정상 작동 확인

6. 하이브리드 포맷 — 현장 쇼케이스 + 온라인 부스
- 포맷
  - 현장 3~4부스 + 온라인 스트리밍(쇼케이스/무대) 동시 운영
  - 온라인 참여자 채팅·Q&A로 연결
- 실행 포인트
  - 카메라 1~2대, 스트리밍 인코더, 별도 담당자(현장/온라인)
  - 온라인 링크·접속 테스트 필수
- 기대 효과
  - 지역 외 원격 참가 유입, 후속 온라인 미팅 예약
- 체크리스트
  - 스트리밍 권한·테스트, 온라인 모더레이터 지정

권장 통합 시나리오(짧은 행사 · 현실적 구성)
- 권장(우선 적용): 오프닝(10분) → 오픈 쇼케이스(30분) → 스피드 피칭/라운드(25분) → 클로징(5분: 타팀 일정 소개) → 네트워킹(자유 10분)
- 이유: 행사 시간이 짧아(120분) 핵심 노출과 네트워킹을 균형 있게 배치함.

2) 사전선발: 쇼케이스·사례클리닉 발표자는 사전신청·간단 심사(형식·관련성) 권장
3) 시간관리: 피치·Q&A 엄격한 타이머 운영(벨·진행자) — 발표자 1회 경고 후 종료
4) 증빙·회계: 모든 지출(특히 기념품·식비)은 전자세금계산서/증빙 확보 필요
5) 개인정보: 설문·쿠폰 추첨 시 개인정보 수집 동의서 필요
